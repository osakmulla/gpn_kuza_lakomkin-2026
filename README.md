# GPN Drilling Segmentation 2026

## О проекте

Проект посвящён решению задачи автоматической сегментации технологических операций буровой установки на основе многомерных временных рядов.

**Цель:** разработать алгоритм, который разделяет данные бурения на 9 технологических классов без использования готовой разметки.

В рамках проекта планируется:
- Исследовать исходный датасет и выявить особенности временных рядов.
- Провести предобработку данных.
- Разработать информативные признаки.
- Выполнить кластеризацию и получить 9 технологических классов.
- Учесть временную последовательность и непрерывность технологических операций.
- Оценить качество сегментации.
- Подготовить итоговые предсказания и отчёт.

## План работы

### Этап 1. Исследовательский анализ данных (EDA)

- Загрузить исходный датасет с помощью Pandas.
- Изучить размерность, типы данных и статистические характеристики.
- Проверить пропуски, дубликаты и аномальные значения.
- Проанализировать распределения признаков.
- Исследовать временную последовательность данных.
- Найти возможные серии и непрерывные интервалы технологических операций.
- Построить графики изменения основных параметров бурения.

**Результат:** понимание структуры данных и особенностей технологических процессов.

### Этап 2. Предобработка данных

- Обработать пропущенные значения.
- Проверить и обработать выбросы.
- Упорядочить данные по времени.
- Определить группы и серии временных рядов.
- Подготовить признаки к дальнейшему анализу и кластеризации.

**Результат:** подготовленный датасет.

### Этап 3. Feature Engineering

- Использовать исходные технологические параметры.
- Создать признаки на основе изменений параметров (разности).
- Рассчитать скользящие средние и стандартные отклонения.
- Исследовать корреляции между признаками.
- Выполнить масштабирование признаков.

**Результат:** набор информативных признаков для сегментации.

### Этап 4. Кластеризация

- Провести первичную кластеризацию с помощью K-Means.
- Проверить альтернативные алгоритмы кластеризации.
- Использовать CatBoost при наличии качественной псевдоразметки.
- Получить ровно 9 кластеров.
- Проанализировать характеристики полученных кластеров.

**Результат:** первичное разделение данных на 9 классов.

### Этап 5. Учёт временной структуры

- Проанализировать последовательность кластеров во времени.
- Устранить короткие случайные переключения между классами.
- Выявить непрерывные интервалы операций.
- Проверить границы между сегментами.
- Сохранить временную согласованность предсказаний.

**Результат:** временно согласованная сегментация.

### Этап 6. Оценка и улучшение качества

- Проверить устойчивость результатов.
- Сравнить различные алгоритмы и параметры.
- Проанализировать размеры и продолжительность сегментов.
- Улучшить качество выделения границ операций.
- Выбрать итоговую конфигурацию алгоритма.

**Результат:** финальная модель сегментации.

### Этап 7. Интерпретация и подготовка решения

- Проанализировать характерные признаки каждого класса.
- Сформулировать гипотезы о соответствующих технологических операциях.
- Подготовить итоговый CSV-файл с предсказаниями.
- Сохранить код и параметры экспериментов.
- Подготовить краткий отчёт с описанием подхода и результатов.

**Результат:** готовое решение для отправки организаторам хакатона.
