
# Отчёт по модели сегментации временных рядов

## 1. Задача

Необходимо разделить многомерный временной ряд буровой установки на 9 классов без эталонной разметки.

Исходный набор содержит 180 901 наблюдение.

## 2. Предобработка

- Данные сортируются по времени и ID.
- Удаляются повторяющиеся ID.
- Временные разрывы более 60 секунд разделяют данные на отдельные серии.
- Обрабатываются одиночные и двойные выбросы.
- Создаётся очищенный набор данных.

## 3. Признаки

Используются исходные параметры буровой установки и их временные характеристики.

Для модели C применяются признаки из набора `state`.

## 4. Сегментация

Для каждой точки рассчитывается различие между средними значениями признаков слева и справа от неё.

Параметры:
- ширина окна: 60 секунд;
- минимальное расстояние между границами: 60 секунд;
- порог: 85-й квантиль полученных оценок.

Точки максимального изменения используются как границы сегментов.

## 5. Кластеризация

Для каждого сегмента рассчитываются средние значения признаков.

Затем применяется KMeans:
- число кластеров: 9;
- random_state: 0;
- n_init: 10;
- вес сегмента равен количеству точек в нём.

Полученные метки назначаются всем точкам соответствующего сегмента.

## 6. Результаты экспериментов

Для модели C:
- количество сегментов: 1933;
- количество классов: 9;
- количество точек: 180 901.

Сравнение кандидатов:
- ARI A–B: 0.517;
- ARI A–C: 0.547;
- ARI B–C: 0.683.

Эти значения показывают согласие моделей между собой, а не точность относительно эталонной разметки.

## 7. Ограничения

Эталонная разметка отсутствует, поэтому официальные ARI и Hungarian-matched Macro F1 вычислить невозможно.

Названия и интерпретации кластеров являются гипотезами и требуют проверки специалистами.
